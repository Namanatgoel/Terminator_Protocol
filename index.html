System Design

Modular Architecture

Built with explicit boundaries. Data flows unidirectionally from the state machine to the AI router, and out through the executor.

db.py
State machine, atomic batch locking (SQLite BEGIN EXCLUSIVE), and immutable audit logs.
llm_engine.py
GPU-accelerated router enforcing Pydantic Literal types to prevent invalid state transitions.
executor.py
Orchestration loop with dependency injection and structured JSON logging.
message_queue.py
Delay queue wrappers ensuring events are pushed before database commits (Outbox pattern).
Logic

Escalation Tiers

Transactions progress through calibrated interventions based on AI analysis of historical context.

1

Silent Retry Low Friction

Triggered on transient failures like insufficient funds or network blips. Schedules a quiet retry queue event without customer contact.

action: 'silent_retry'
2

WhatsApp Ping Direct Nudge

Used for repeated failures or abandoned high-intent checkouts. Dispatches a direct payment link via WhatsApp.

action: 'whatsapp_ping'
3

Voice Negotiation High Value

If context indicates price sensitivity, the system authorizes a dynamic discount and initiates a real-time negotiation call.

action: 'voice_call' | offer_authorized: true
4

Terminal Alert Final Attempt

When all soft channels are exhausted, an urgency-framed message is sent. Failure marks the transaction as lost.

action: 'fomo_alert'
